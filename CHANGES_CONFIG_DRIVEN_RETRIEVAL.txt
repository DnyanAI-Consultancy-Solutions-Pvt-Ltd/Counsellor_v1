CONFIG-DRIVEN BROAD RETRIEVAL UPDATE

1. Semantic retrieval no longer searches for the student's exact percentile.
2. Percentile and college count are intentionally excluded from retrieval-plan prompts.
3. Retrieved chunks are filtered using structured branch and category metadata.
4. Compact evidence context allows many more grounded college/branch candidates to fit within the Groq context limit.
5. Dream/Target/Safe classification is performed numerically in Python using configurable margins:
   margin = historical cutoff - student percentile
6. Portfolio ratios and margin windows are controlled through environment settings, not fixed college rules.
7. The LLM proposes grounded rows and explanations; Python enforces category, cutoff, zone, uniqueness and counts.

Recommended .env values:
RETRIEVAL_LIMIT=120
RESULTS_PER_QUERY=30
MAX_CONTEXT_CHARACTERS=16000
LLM_MAX_TOKENS=3000
DREAM_MARGIN_MIN=0.5
DREAM_MARGIN_MAX=5.0
TARGET_MARGIN_MIN=-1.5
TARGET_MARGIN_MAX=0.5
SAFE_MARGIN_MIN=-5.0
SAFE_MARGIN_MAX=-1.5
DREAM_RATIO=0.30
TARGET_RATIO=0.40
SAFE_RATIO=0.30
