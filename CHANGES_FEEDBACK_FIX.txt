Feedback reliability update
===========================

1. Initial recommendation generation now makes multiple retrieval/completion attempts.
2. Missing Dream/Target/Safe counts are reported explicitly.
3. Feedback is first converted by the LLM into structured operations.
4. Add/remove/rerank/replace actions are executed deterministically in Python.
5. "Add N" validates the exact number of unique grounded additions.
6. Removal validates that zero matching rows remain.
7. Existing session recommendations are preserved unless an operation changes them.
8. Duplicate and evidence validation results are returned in the API response.
9. Session-specific JSON and Excel files continue to be updated in place.

New file: services/preference_service.py
Updated: agents/counsellor.py, agents/feedback.py, config/settings.py
